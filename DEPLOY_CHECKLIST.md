## **TROUBLESHOOTING**

**Problem:** Pages still showing old design
- **Solution:** Wait 5 more minutes and do a hard refresh
  - Windows: Ctrl + Shift + R
  - Mac: Cmd + Shift + R
  - Mobile: Close and reopen browser

**Problem:** 404 errors on some pages
- **Solution:** Make sure ALL 6 files were uploaded, check filenames match exactly

**Problem:** Styling looks broken
- **Solution:** Verify styles.css uploaded correctly. Hard refresh browser.

**Problem:** Card creator not working
- **Solution:** Make sure card-creator.html uploaded and is valid HTML
